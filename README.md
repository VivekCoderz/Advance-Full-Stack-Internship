# Advance Full Stack Internship

My JavaScript assessments and React practice projects from the Advance Full Stack internship.

## JavaScript assessments

Each file holds the answers to one assessment. The questions are written as comments above each answer.

| File | Topics |
|---|---|
| `Assessment1.js` | `let`/`const`, block scope, arrow functions, template literals, destructuring, default parameters, rest/spread, `map`/`filter`/`reduce` |
| `Assessment2.js` | Scope, nested functions, closures and lexical scope, functions passed as arguments |
| `Assessment3.js` | Objects, `this`, prototypes and `Object.create` |
| `Assessment4-5.js` | `this` in different contexts, classes, errors (`TypeError`/`ReferenceError`), intro to async code |
| `Assessment6.js` | Callbacks and `setTimeout` |
| `Assessment7.js` | Promises |
| `Assessment8.js` | `async`/`await` |
| `old.js`, `new.js` | Scratch files |

Run any file with Node:

```bash
node Assessment1.js
```
